# Application de gestion Multilocations ou ProjetSGML

## Description

**ProjetSGML** est une application de gestion développée dans le cadre d'un projet académique.
L'objectif du projet est de concevoir une application permettant de gérer 
l'authentification des utilisateurs et l'accès sécurisé à un système informatique.

L'application met en œuvre les concepts de programmation orientée objet, 
de gestion des interfaces graphiques et de manipulation des données.

## Fonctionnalités

* Authentification des utilisateurs
* Gestion de la connexion au système
* Validation des informations d'identification
* Gestion des accès utilisateurs
* Interface utilisateur simple et intuitive

## Technologies utilisées

* C#
* .NET / Visual Studio
* Windows Forms (ou WPF selon l'interface utilisée)
* Git et GitHub

## Installation

1. Cloner le dépôt :

```bash
git clone https://github.com/siesidoine/ProjetSGML.git
```

2. Ouvrir le projet avec Visual Studio.

3. Restaurer les dépendances si nécessaire.

4. Compiler et exécuter l'application.
